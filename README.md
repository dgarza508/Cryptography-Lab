# Cryptography-Lab
From-scratch cryptography lab implementing number theory and discrete log algorithms for educational purposes.

# Overview

The project implements core cryptographic primitives and algorithms from first principles, including:

- Modular arithmetic and number theory tools
- Discrete logarithm solvers (naive, BSGS, Pohlig–Hellman)
- Chinese Remainder Theorem
- Diffie–Hellman key exchange
- RSA key generation, encryption, and decryption (Coming Soon)
- Primality testing (Fermat, Miller–Rabin) (Coming Soon)
- Elliptic curve cryptography (toy curves) (Coming Soon)
- Experimental attacks and demonstrations (Coming Soon) 

The goal is to understand how and why cryptographic systems work, not to provide production-ready cryptography.
